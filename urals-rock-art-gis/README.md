## 🧭 Методология (полный цикл анализа)



### 1. Предобработка данных

- Проекция всех слоёв: WGS 84 / UTM зона 40N (EPSG:32640)
- Создание бинарных полей культур (25 полей) и эпох (6 полей) с помощью SQL-выражений в QGIS

### 2. Расчёт изохрон пешей доступности

- Загрузка ЦМР FABDEM → агрегирование до 60 м для ускорения
- Вычисление уклона (`r.slope.aspect` в GRASS)
- Расчёт стоимости ходьбы по функции Тоблера:

  `speed = 6 * exp(-3.5 * abs(slope + 0.05))`
- Модуль `r.cost` (GRASS) – накопленная стоимость от всех писаниц, буфер 40 км
- Классификация времени (секунды → минуты → 8 зон) через Raster Calculator (см. ниже)

### 3. Классификация и векторизация

Выражение в калькуляторе растра (вложенные IF):



```
if( ("accumulated_cost_40km_final@1" / 60) <= 15, 1,

if( ("accumulated_cost_40km_final@1" / 60) <= 30, 2,

if( ("accumulated_cost_40km_final@1" / 60) <= 60, 3,

if( ("accumulated_cost_40km_final@1" / 60) <= 90, 4,

if( ("accumulated_cost_40km_final@1" / 60) <= 120, 5,

if( ("accumulated_cost_40km_final@1" / 60) <= 180, 6,

if( ("accumulated_cost_40km_final@1" / 60) <= 240, 7, 8 )))))))
```



- Векторизация (`GDAL Polygonize`) → растворение (`Dissolve`) → полигоны изохрон

### 4. Агрегация и подсчёт памятников

- Инструмент QGIS **«Агрегирование» (Aggregate)**
- Группировка по `zone_id`, суммирование бинарных полей культур
- Получена сводная таблица (памятники каждой культуры в каждой зоне)

### 5. Визуализация и статистика

- Карты изохрон с точечными слоями памятников (раскраска по эпохам)
- Столбчатые диаграммы с накоплением (культуры, эпохи)

**Пример (классификация писаниц по эпохам):**

```sql
CASE 
    WHEN "Мезолит_int" = 1 THEN 'Мезолит'
    WHEN "Неолит_int" = 1 THEN 'Неолит'
    WHEN "Энеолит_int" = 1 THEN 'Энеолит'
    WHEN "Эпоха развитой бронзы_int" = 1 THEN 'Бронзовый век'
    WHEN "Ранний железный век_int" = 1 THEN 'Ранний железный век'
    WHEN "Эпоха средневековья_int" = 1 THEN 'Средневековье'
    ELSE 'Не атрибутировано'
END
```
